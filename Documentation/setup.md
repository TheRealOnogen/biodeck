# How to set up Biodeck

```bash
$ git clone https://git.onogenatedwater.dpdns.org/GizmoTM_Inc/Biodeck
$ cd Biodeck
$ npm install
$ node server.js
```
Boom, biodeck works

# How to set up themes

1. Make a theme
2. Add it to themes.json<br>
Example:
```json
  {
  "name": "test",
  "displayName": "Testing theme",
  "file": "styles_test.css"
  }
```
